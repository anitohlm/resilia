Brief about the idea

AI-Assisted Community Disaster Coordination Operating Under Severe Network Degradation
  • ●
    The 72-Hour Blackout Crisis: Severe climate disasters knock out power grids and cellular infrastructure in vulnerable coastal river basins (modeled on the Marikina River). Conventional cloud-only tools fail with blank loading spinners during the critical first 72 hours.
  • ●
    Hybrid Dual-Engine AI Architecture: Combines Google Gemini 3.8 Flash in the cloud for deep situational reasoning and predictive clustering with zero-overhead client IndexedDB edge persistence (15 stores) and deterministic local algorithms when connectivity drops.
  • ●
    Tri-Role Community Coordination: Tailored, low-friction mobile workflows for Residents (instant SOS beacon & shelter locator), Responders (START casualty triage & QR wristbands), and Coordinators (shelter capacity & cryptographic dispatch gate) operating with zero active internet.
  • ●
    Anti-Hallucination Emergency Safety: Deterministic safety boundaries grounded strictly in Philippine NDRRMC and DOH disaster SOPs, requiring human coordinator cryptographic authorization for emergency dispatches.
  • ●
    Rigorous Verification Baseline: Evaluated against simulated Marikina River Basin telemetry (Typhoon Ondoy / Ulysses baselines, Alarm Level 3 at 18m water depth) backed by automated test validation.

Opportunities

Addressing Critical Gaps in Existing Disaster Technologies
  • ●
    How different is it from any of the other existing ideas?
    • Local-First Edge Durability: Unlike cloud-only apps that freeze when cell towers submerge, Resilia executes complete workflows via local browser caching for degraded networks with sub-15ms write latency.
    • Role-Tailored Ground Operations: Dedicated cockpits for Residents, Responders, and Coordinators instead of generic forms.
  • ●
    How will it be able to solve the problem?
    • Sub-Second Local Logging: Citizen reports commit instantly to device storage and queue for automatic sync upon reconnection.
    • Transparent Vulnerability Scoring: Prioritizes bedridden seniors, infants, and chronic medical cases over first-come-first-served queues.
    • Tamper-Resistant Ayuda QR Ledger: 24-hour distribution cooldown timer prevents duplicate claims and relief hoarding.
  • ●
    USP of the proposed solution:
    • Adaptive Dual-Engine AI Continuum: Unifies Google Gemini 3.8 Flash in the cloud for macro situation synthesis with zero-spend deterministic edge execution when connectivity is completely severed.

Technologies to be used in the solution

Google Cloud Platform, Modern Edge Runtime, and Mobile Web Technologies
  • ●
    Google Cloud & AI Ecosystem: Google Gemini 3.8 Flash (@google/genai SDK), Google Cloud Run auto-scaling microservices, Cloud Firestore transactional datastore, Google Maps Platform.
  • ●
    Frontend & Mobile PWA: React 19, TypeScript 7.0, Vite 8.3 build engine, Tailwind CSS 4.3, Lucide React iconography, Workbox Service Worker for offline asset pre-caching.
  • ●
    Edge Persistence & Security: Browser IndexedDB across 15 structured stores, Client-side QR / Barcodes, Web Crypto SHA-256 hashing, Role-Based Access Control (RBAC).
  • ●
    Edge Micro-Server & Mesh Compatibility: Node.js 22 LTS, Express 4.21, Docker, compatible with low-cost $35 Raspberry Pi local mesh nodes.

Estimated implementation cost (optional)

Frugal, Highly Scalable Cost Model for Community & LGU Deployments
  • ●
    Citizen Edge Client (Resident / Responder): $0.00 incremental cost. Runs directly in standard mobile web browsers as an installable PWA without app store licensing fees.
  • ●
    Community Shelter Local Node (Optional): ~$35–$60 one-time hardware cost per shelter (Raspberry Pi 4/5 or repurposed PC serving local Wi-Fi mesh).
  • ●
    Google Cloud Run & Cloud Firestore: $15–$50 / month during active disaster activations; serverless model scales to zero during calm periods.
  • ●
    Google Gemini 3.8 Flash API: ~$10–$30 / month during typhoon activations; prompt caching and bounded schemas keep token usage minimal.
  • ●
    Total Community Pilot Budget: Under $500 for a multi-shelter pilot across Marikina River Basin barangays.
